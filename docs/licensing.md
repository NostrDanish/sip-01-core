# Licensing

The current licensing state of the repository, stated factually. No decision has been made; nothing on this page is legal advice or interpretation.

## The boundary note

This repository currently has **no LICENSE file**. An earlier revision of the README stated "MIT", but no LICENSE file was ever committed, so the actual terms are **undetermined**. This contradiction must be resolved by the project owner before any third-party reuse or distribution of any layer.

Until then:

- No reuse or distribution rights are granted by default.
- No terms should be assumed for any derivative, open or closed.

This mirrors the note in the [root README](../README.md#open-contracts-closed-components) and the remaining-debt entry in the [Extraction map](EXTRACTION-MAP.md). It is recorded as debt precisely so it is not rediscovered the hard way.

## What this means for the guides

The architecture and guides describe the code as open contracts with replaceable components — that is a *technical* property of the design (interfaces, seams, boundaries). It is **not** a grant of rights. Building against the interfaces described here, redistributing the library, or shipping derivatives all wait on the owner's licensing decision.

When the owner commits a LICENSE file, this page will be updated to state the chosen terms.
